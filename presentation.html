Problem & Opportunity Slide 2 / 8

The Digital Wellbeing Dilemma

Conventional productivity tools treat all browsing identically, failing to support purposeful work on modern social feeds.

⚠️ Why Existing Tools Fail

  • Blind Timers: Lock out platforms after 15 mins, interrupting critical research alongside distraction.
  • Feed Blockers: Strip feeds completely, removing announcements, discussions, and updates.
  • Opening Delays: Introduce a 5-second pause at site entry, but do nothing once a user drifts 10 minutes later.
  • Reactance: Users bypass or uninstall punitive blockers when they feel restricted.

💡 The Entropilo Opportunity

  • Behavior-Aware: Responds to how a person is browsing, rather than simply how long they have stayed.
  • Metacognitive Mirror: Holds up the user’s own stated goal against their current actions.
  • Graceful Friction: Uses subtle sensory desaturation to reduce dopamine feedback without breaking functionality.
Opportunity: Distinguishing intention from automation Privacy-First Heuristics
Proposed Solution Slide 3 / 8

The Entropilo Trinity

An end-to-end cognitive loop that preserves intentional browsing and interrupts passive trance states.

1. Intent Contract

A lightweight prompt when opening YouTube or X/Twitter asks: "What is your intention for this visit?"

Saves declared goal in local tab memory with preset or custom text.

2. Fugue Engine

A local heuristic monitoring rolling scroll velocity, reading dwell time pauses, and interaction density.

Computes real-time Zombification Score (0-100) with warm-up grace gates.

3. Behavioral Mirror

Injects an in-feed reflection card comparing declared intent with measured telemetry: "Scrolled 45 posts, clicked 0 links."

Provides a conscious choice to refocus or exit cleanly.
Non-Punitive • Reversible • Metacognitive Dynamic Site Adapters
System Workflow Slide 4 / 8

The Adaptive Intervention Cycle

How signals flow seamlessly from initial intent to mindful decision making.

STEP 1 Declare Intent

User enters feed and sets goal: "Watch tutorial" or "Check hackathon news".

STEP 2 Signal Tracking

rAF samples scroll speed. Pauses to read count as positive dwell. Video clicks reward clarity.

STEP 3 Progressive Entropy

If rapid scrolling continues without clicks, page desaturates (30% -> 65% -> 85% grayscale).

STEP 4 Mirror & Reset

In-feed card prompts reflection. User clicks 'Refocus & Reset' to immediately restore full clarity.

🛡️ Warm-Up Grace Period Protection

Initial 40-second grace window prevents false triggers when a user first lands and skims the top of the feed.

Closed Feedback Loop Zero Page Reloads Required
Product Features Slide 5 / 8

Engineered for Focus, Not Lockouts

A complete suite of wellbeing mechanics and developer tools.

  • Calculates rolling drift index via scroll velocity, dwell duration, and clicks.

Technologies Used Slide 6 / 8

Modern, Lightweight & Zero-Dependency

Built entirely on native browser APIs to ensure minimal resource overhead and absolute privacy.

📦 Extension Framework

  • Chrome Manifest V3: Latest modern extension standard with background service workers.
  • Storage API: Session & local tab synchronization with zero cloud transmission.
  • ActiveTab & Badge APIs: Reactive extension toolbar badge color & score indication.

⚡ Content Script Architecture

  • requestAnimationFrame: High-precision, jitter-free scroll velocity sampling.
  • IntersectionObserver: Accurate tracking of unique post views and impressions.
  • MutationObserver: Dynamic infinite-scroll feed container attachment.

🎨 CSS & Isolation Layer

  • Namespaced Scopes: Resets styling to prevent conflict with YouTube/Twitter styles.
  • Dynamic CSS Injections: Non-destructive inline stylesheets for filter transitions.
  • Polymer & SPA Hooking: Listens to yt-navigate-finish on YouTube.

🧪 Verification & Tooling

  • Node.js Automated Test Suite: Verified scoring models, time-gates, and decay math.
  • Pure Python Asset Generator: Programmatic PNG icon generation without external libraries.
  • EchoNet Test Engine: Built-in procedural social feed generator.
